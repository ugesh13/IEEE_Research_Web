| **RQ1: Model Performance** | Phase 11: Multi-Model Evaluation across LR, RF, HGB | Training fold ($N = 22,815$, $20,149$ students) with 5-fold grouped CV; Validation ($N = 4,889$, $4,318$ students) | ROC-AUC, PR-AUC, Accuracy, At-Risk Recall, Precision, $F_1$, Brier | In $S_2$, HGB achieved Val ROC-AUC $0.8425$, PR-AUC $0.8478$, Acc $76.44\%$, Recall $80.86\%$, Prec $76.03\%$, $F_1 = 0.7837$, Brier $0.1624$. | **RQ2: Incremental Scenario Gains** | Phase 11: Nested Scenario Progression ($S_0 \rightarrow S_1 \rightarrow S_2$) | Validation set ($N = 4,889$); Holdout test set ($N = 4,889$) | ROC-AUC, PR-AUC, Recall, Error Counts | Validation HGB ROC-AUC progressed: $S_0 = 0.6208 \rightarrow S_1 = 0.7592$ ($\mathbf{+0.1384}$) $\rightarrow S_2 = 0.8425$ ($\mathbf{+0.0833}$). The largest incremental ROC-AUC gains were observed after adding early assessment and VLE interaction features. | Observational data only; VLE clicks and early submissions reflect student engagement behaviors but do not establish causality. |
| **RQ2: Scenario Partition Robustness** | Phase 15: Scenario Evaluation across 5 Random Seeds | 5 independent student-grouped splits (seeds 7, 21, 42, 84, 123; 0 student overlap) | ROC-AUC Mean ± SD, Min, Max | Across 5 seeds: $S_0 = 0.6192 \pm 0.0030$; $S_1 = 0.7584 \pm 0.0026$; $S_2 = 0.8405 \pm 0.0013$. Monotonicity ($S_0 < S_1 < S_2$) held in $100\%$ ($5/5$) of seeds. | The consistent S0 < S1 < S2 ROC-AUC progression across all five evaluated partitions provides robustness evidence supporting the incremental contribution of early assessment and VLE features. | Evaluated across 5 random seeds; does not represent an infinite-sample permutation test. |
| **RQ3: Global Feature Attribution** | Phase 13: SHAP Feature Attribution | Training background ($N_{\text{bg}} = 100$), evaluated across 29 raw predictors (68 transformed features) | Mean Absolute SHAP ($| \phi |$) and % of Total Attribution | Total attribution = $3.9196$. | **RQ3: Top Predictor Identification** | Phase 13: Granular Predictor Attribution | Transformed features mapped back to 29 raw features | Mean Absolute SHAP ($| \phi |$) and Directionality | Top features: `early_avg_score_d30` ($0.4285$), `early_vle_active_days_d30` ($0.3842$), `early_vle_total_clicks_d30` ($0.3120$), `has_early_assessment_submission_d30` ($0.2856$). | Regular, distributed VLE presence (`active_days`) had higher mean absolute attribution than aggregate click volume. Timely assignment submission strongly lowers risk probability. | Correlated features share Shapley credit; feature interactions are approximated by sample perturbation. |
| **RQ3: Local Decision Auditing** | Phase 13: Instance-Level Waterfall Analysis | Representative instances across TP, TN, FP, FN quadrants | Local SHAP contributions ($\phi_i$) and log-odds shift | True Positives were driven by absent submissions and low active days. False Negatives ($FN = 455$) frequently had high Day 30 engagement but experienced late-semester disruptions. | Day 30 early-warning predictions cannot detect late-semester exogenous life crises occurring after the observation window closes. | Qualitative case audits illustrate model mechanics but cannot quantify every individual failure mode. |
| **RQ4: Demographic Subgroup Performance** | Phase 14: Subgroup Parity and Error Auditing | Holdout test partition ($N = 4,889$, $4,318$ unique students) evaluated under fixed $\theta^* = 0.45$ | Subgroup Recall, Precision, FPR, FNR, Cluster 95% CI | Female Recall = $81.79\%$ [$79.6, 84.0$] vs Male Recall = $82.85\%$ [$80.9, 84.8$] ($\Delta = 1.06\%$). Small sample sizes in certain strata ($n < 100$). |
| **RQ4: Socioeconomic & Education Strata** | Phase 14: IMD Decile & Prior Attainment Auditing | Holdout test partition ($N = 4,889$) under fixed $\theta^* = 0.45$ | Subgroup Recall, Precision, Base Rate | IMD Recall ranged from $80.28\%$ (least deprived) to $84.23\%$ (most deprived). Prior education Recall ranged from $78.87\%$ (Higher Ed) to $84.13\%$ (Lower than A Level). | Model sensitivity is preserved across socioeconomic deprivation deciles and educational backgrounds. | IMD is an area-based deprivation measure (England/Wales only); missing for non-England students (handled via explicit category). |
| **Operational Threshold Trade-offs** | Phase 12 & 15: Decision Threshold Sensitivity | Holdout test set ($N = 4,889$) evaluated across grid $\theta \in [0.20, 0.80]$ | Recall, Precision, $F_1$, Specificity, TP, FN, FP | $\theta^* = 0.45$: Recall = $82.38\%$, Prec = $74.68\%$, $F_1 = 0.7834$, $\text{TP} = 2,127, \text{FN} = 455$. $\theta = 0.50$: Recall = $80.60\%$, Prec = $75.84\%$, $F_1 = 0.7814$, $\text{TP} = 2,081, \text{FN} = 501$. | At the frozen threshold of 0.45, the model identifies 46 additional At-Risk observations compared with the 0.50 benchmark, reducing the false-negative count from 501 to 455. | The F1-score remains relatively stable across thresholds from 0.35 to 0.50. Threshold selection reflects an operational caseload constraint, not universal optimality. |
| **Resampling Uncertainty Sensitivity** | Phase 15: Bootstrap Resampling Comparison | Holdout test set ($N = 4,889$, $4,318$ students); $B = 1,000$, seed 42 | 95% Percentile Confidence Interval Widths | Observation bootstrap intervals were $3.4\%$ to $6.1\%$ narrower than cluster bootstrap intervals (e.g., Recall CI width $0.0283$ vs $0.0293$; ROC-AUC CI width $0.0202$ vs $0.0214$). | The student-level cluster bootstrap was retained as the preferred uncertainty estimation method because it accounts for the dependence induced by multiple course presentations from the same student. | Resampling assumes sample represents the population; holdout test cohort is finite ($4,318$ unique students). |
| **Class-Weight Sensitivity** | Phase 15: Loss Function Re-weighting Audit | Validation ($N = 4,890$) and Holdout test ($N = 4,889$) sets | ROC-AUC, Specificity, Precision, $F_1$, False Positive Count | Balanced weighting changed ROC-AUC marginally ($-0.0002$ on test), but increased false alarms by $157$ ($721 \rightarrow 878$), lowering Specificity ($68.75\% \rightarrow 65.31\%$) and Prec ($74.68\% \rightarrow 73.15\%$). | Under the evaluated configuration, unweighted training produced higher specificity, precision and F1 than balanced weighting, while ROC-AUC differed only marginally. | Descriptive comparison only; did not alter primary model selection. |
